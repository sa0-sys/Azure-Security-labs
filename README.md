## 📖 About This Repository

This repo documents my journey preparing for the **SC-500: Implementing End-to-End Security Controls for Cloud and AI Workloads** exam. Each folder maps directly to an exam domain, and contains real labs deployed against a live Azure subscription — not just notes.

The goal: prove the skills, not just study them.
